# 投票和采纳功能完善报告

## 功能概述

本次完善了QA平台的投票和采纳功能，包括问题投票、回答投票和回答采纳三个核心功能模块。

## 完善内容

### 1. 后端API完善

#### 1.1 问题投票功能

**新增API端点：**
- `POST /api/questions/{id}/vote` - 问题投票
- `GET /api/questions/{id}/vote` - 获取问题投票状态

**功能特性：**
- 支持点赞和取消点赞
- 防止用户给自己的问题投票
- 实时更新投票数量
- 返回详细的投票状态信息

**请求示例：**
```bash
# 投票
curl -X POST -H "Content-Type: application/json" -H "X-User-Id: 2" \
  -d '{"vote": 1}' http://localhost:8080/api/questions/1/vote

# 查询状态
curl -H "X-User-Id: 2" http://localhost:8080/api/questions/1/vote
```

#### 1.2 回答投票功能

**新增API端点：**
- `POST /api/questions/answers/{answerId}/vote` - 回答投票
- `GET /api/questions/answers/{answerId}/vote-status` - 获取回答投票状态

**功能特性：**
- 支持点赞和取消点赞
- 防止用户给自己的回答投票
- 实时更新投票数量
- 返回详细的投票状态信息

#### 1.3 回答采纳功能

**完善API端点：**
- `POST /api/questions/{questionId}/accept` - 采纳回答

**功能特性：**
- 只有问题作者才能采纳回答
- 采纳新回答时自动取消之前的采纳
- 更新问题状态为已解决
- 完善的权限检查和错误处理

### 2. 数据库模型完善

#### 2.1 Question实体增强

```java
@Column(nullable = false)
private Integer votes = 0;  // 投票数（点赞数）

@ManyToMany
@JoinTable(
    name = "question_votes",
    joinColumns = @JoinColumn(name = "question_id"),
    inverseJoinColumns = @JoinColumn(name = "user_id")
)
@JsonIgnore
private Set<User> voters = new HashSet<>();  // 给问题投票的用户

// 添加投票
public void addVote(User user) {
    voters.add(user);
    user.getVotedQuestions().add(this);
    this.votes = voters.size();
}

// 取消投票
public void removeVote(User user) {
    voters.remove(user);
    user.getVotedQuestions().remove(this);
    this.votes = voters.size();
}
```

#### 2.2 User实体增强

```java
// 用户点赞的问题
@ManyToMany(mappedBy = "voters")
@JsonIgnore
private Set<Question> votedQuestions = new HashSet<>();
```

- `addVote()` 和 `removeVote()` 方法
