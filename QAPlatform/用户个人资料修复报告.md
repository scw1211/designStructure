```java
@GetMapping("/{id}/questions")
public ResponseEntity<Page<Question>> getUserQuestions(
    @PathVariable Long id,
    @RequestParam(defaultValue = "0") int page,
    @RequestParam(defaultValue = "10") int size,
    @RequestParam(defaultValue = "createdAt") String sortBy,
    @RequestParam(defaultValue = "desc") String sortDirection)
```

```java
@GetMapping("/{id}/stats")
```

## 🎨 前端修复内容

### 1. 修复UserProfile.vue数据加载

#### 用户信息加载
```javascript
const loadUserInfo = async () => {
  const [userResponse, statsResponse] = await Promise.all([
    api.get(`/users/${userId.value}`),
    api.get(`/users/${userId.value}/stats`)
  ])
  
  // 合并用户基本信息和统计信息
  userInfo.value = {
    ...userResponse.data,
    ...statsResponse.data
  }
}
```

#### 用户问题加载
```javascript
const loadUserQuestions = async () => {
  const response = await api.get(`/users/${userId.value}/questions`, {
    params: { 
      page: 0,
      size: 20,
      sortBy: questionSort.value === 'newest' ? 'createdAt' : 'viewCount',
      sortDirection: questionSort.value === 'oldest' ? 'asc' : 'desc'
    }
  })
  
  // 处理数据映射
  userQuestions.value = questions.map((question: any) => ({
```
