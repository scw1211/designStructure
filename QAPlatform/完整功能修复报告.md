## 问题分析与解决

### 1. 数据持久化问题 ✅ 已解决

**问题原因：**
- 前端在API调用失败时使用模拟数据
- 模拟数据不会保存到数据库
- 用户刷新页面后模拟数据丢失

**解决方案：**
- 移除了`QuestionDetail.vue`中的所有模拟数据
- 修复了后端Hibernate懒加载异常
- 确保所有数据都来自真实的数据库

### 2. 后端懒加载异常 ✅ 已解决

**问题原因：**
```
LazyInitializationException: could not initialize proxy [com.qaplatform.model.User#1] - no Session
```
- Answer实体的author字段使用了`FetchType.LAZY`
- 在Hibernate Session关闭后尝试序列化JSON时出现异常

**解决方案：**
```java
// 在AnswerRepository中添加预加载查询
@Query("SELECT a FROM Answer a JOIN FETCH a.author WHERE a.question.id = :questionId ORDER BY " +
       "CASE WHEN :sort = 'votes' THEN a.voteCount END DESC, " +
       "CASE WHEN :sort = 'oldest' THEN a.createdAt END ASC, " +
       "CASE WHEN :sort = 'newest' THEN a.createdAt END DESC")
List<Answer> findByQuestionIdWithAuthorSorted(@Param("questionId") Long questionId, @Param("sort") String sort);

// 在AnswerServiceImpl中使用预加载方法
@Override
public Page<Answer> getAnswersByQuestion(Long questionId, String sort, Pageable pageable) {
    List<Answer> answers = answerRepository.findByQuestionIdWithAuthorSorted(questionId, sort);
    
    // 手动实现分页
    int start = (int) pageable.getOffset();
    int end = Math.min(start + pageable.getPageSize(), answers.size());
    
    List<Answer> pageContent = start > answers.size() ? 
        java.util.Collections.emptyList() : answers.subList(start, end);
    
    return new PageImpl<>(pageContent, pageable, answers.size());
}
```

### 3. 前端模拟数据清理 ✅ 已解决

**修复前：**
```javascript

answers.value = [
  {
    id: 1,
    content: '这是一个很好的问题！我建议你从Spring Boot官方文档开始学习...',
    author: { id: 2, username: 'expert1', avatar: '' },
    // ...更多静态数据
  }

```

**修复后：**
```javascript
// 获取回答列表
const loadAnswers = async () => {
  loadingAnswers.value = true
  try {
    const questionId = route.params.id
    const response = await api.get(`/questions/${questionId}/answers`, {
      params: { sort: sortBy.value }
    })
    
    // 处理分页数据格式
    if (response.data.content && Array.isArray(response.data.content)) {
      answers.value = response.data.content
    } else if (Array.isArray(response.data)) {
      answers.value = response.data
    } else {
      answers.value = []
    }
    
    console.log('✅ 回答列表加载成功:', answers.value.length, '个回答')
  } catch (error) {
    console.error('❌ 加载回答失败:', error)
    ElMessage.error('加载回答失败')
    // 不使用模拟数据，保持空数组
    answers.value = []
  } finally {
    loadingAnswers.value = false
  }
}
```
