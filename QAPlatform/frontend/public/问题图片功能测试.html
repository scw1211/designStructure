🔗 问题图片 API 接口

POST /api/questions/{questionId}/images - 上传问题图片

POST /api/questions/{questionId}/images/batch - 批量上传图片

GET /api/questions/{questionId}/images - 获取问题所有图片

GET /api/questions/images/{imageId}/file - 获取图片文件

DELETE /api/questions/images/{imageId} - 删除指定图片

DELETE /api/questions/{questionId}/images - 删除问题所有图片
