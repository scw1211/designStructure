# 🎯 问题关注和评论功能实现报告

## 📋 需求背景

用户发现系统中的 `question_followers` 和 `comments` 表没有数据，并且问题浏览次数功能不完整，要求实现这些缺失的功能。

## 🔍 问题分析

### 原有功能状态

1. **✅ 数据库表结构** - 已存在但未被使用
   - `question_followers` - 问题关注关系表
   - `comments` - 评论表
   - `questions.view_count` - 浏览次数字段

2. **✅ 实体模型** - 已完整定义
   - Question.java - 包含关注者和浏览次数字段
   - Comment.java - 评论实体
   - User.java - 包含关注关系

3. **❌ API接口** - 缺失控制器实现
4. **❌ 前端交互** - 无相应的前端功能

## 🚀 实现方案

### 1. 问题关注功能

#### API设计
```bash
# 关注/取消关注问题
POST /api/questions/{id}/follow?follow=true|false

# 检查关注状态
GET /api/questions/{id}/follow-status

# 获取问题关注者列表
GET /api/questions/{id}/followers
```

#### 功能特性
- ✅ 支持用户关注/取消关注问题
- ✅ 实时统计关注者数量
- ✅ 提供关注状态查询
- ✅ 展示关注者列表
- ✅ 集成观察者模式通知系统

### 2. 评论功能

#### API设计
```bash
# 为回答添加评论
POST /api/comments/answers/{answerId}

# 获取回答的评论列表
GET /api/comments/answers/{answerId}

# 更新评论
PUT /api/comments/{commentId}

# 删除评论
DELETE /api/comments/{commentId}

# 获取问题的所有评论
GET /api/comments/questions/{questionId}

# 用户评论统计
GET /api/comments/stats/user/{userId}
```

#### 功能特性
- ✅ 支持对回答进行评论
- ✅ 评论权限控制（作者可编辑/删除）
- ✅ 按时间排序显示评论
- ✅ 评论统计和汇总
- ✅ 支持评论搜索和分页

### 3. 浏览次数功能

#### API设计
```bash
# 增加问题浏览次数
POST /api/questions/{id}/view
```

#### 功能特性
- ✅ 用户访问问题时自动增加浏览次数
- ✅ 防重复计数机制
- ✅ 浏览次数实时更新
