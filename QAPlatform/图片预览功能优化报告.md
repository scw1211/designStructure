# 📸 图片预览功能优化报告

## 🎯 问题描述

用户反馈：**"点进去图片按ESC退不出去"**

### 原始问题分析
- **现象**：点击问题详情页的图片时，使用`window.open()`在新窗口打开图片
- **问题**：无法通过ESC键关闭图片预览
- **用户体验**：需要手动关闭浏览器标签页，操作繁琐

## ✨ 解决方案

### 技术改进
使用 **Element Plus 的 `el-image` 组件** 替代原始的 `window.open()` 方案

### 核心变更

#### 1. 组件替换
```vue
<!-- 修改前 -->
<img
  :src="`/api/questions/images/${image.id}/file`"
  :alt="image.fileName"
  loading="lazy"
  @click="previewImage(image)"
/>

<!-- 修改后 -->
<el-image
  :src="`/api/questions/images/${image.id}/file`"
  :alt="image.fileName"
  fit="cover"
  loading="lazy"
  :preview-src-list="imagePreviewList"
  :initial-index="getImageIndex(image.id)"
  preview-teleported
/>
```

#### 2. 功能函数添加
```javascript
// 计算属性：图片预览列表
const imagePreviewList = computed(() => {
  return questionImages.value.map(image => `/api/questions/images/${image.id}/file`)
})

// 获取图片在预览列表中的索引
const getImageIndex = (imageId: number) => {
  return questionImages.value.findIndex(image => image.id === imageId)
}

// 格式化文件大小
const formatFileSize = (size: number) => {
  if (!size) return '0 B'
  const units = ['B', 'KB', 'MB', 'GB']
  let fileSize = size
  let unitIndex = 0
  
  while (fileSize >= 1024 && unitIndex < units.length - 1) {
    fileSize /= 1024
    unitIndex++
  }
  
  return `${fileSize.toFixed(1)} ${units[unitIndex]}`
}
```

#### 3. 样式优化
```css
.image-item :deep(.el-image) {
  width: 100%;
  height: 150px;
  display: block;
}

.image-item :deep(.el-image img) {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```
