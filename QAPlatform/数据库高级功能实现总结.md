## 📊 新增的数据库视图（5个）

### 1. v_user_statistics - 用户统计视图
```sql
-- 实时计算用户的所有统计数据
SELECT 
    user_id, username, email, reputation, role,
    total_questions, total_answers, total_votes_received,
    accepted_answers, questions_solved_percentage,
    active_days_7, active_days_30, last_activity_date
FROM users u
LEFT JOIN question/answer/vote statistics
```

### 2. v_trending_questions - 热门问题视图
```sql
-- 基于复杂算法的热门问题排序
SELECT 
    question_id, title, vote_score, view_count, 
    answer_count, created_at, trending_score
FROM questions
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
ORDER BY trending_score DESC
```

### 3. v_expert_users - 专家用户视图
```sql
-- 基于回答质量和采纳率的专家识别
SELECT 
    user_id, username, total_answers, accepted_answers,
    acceptance_rate, expertise_score, reputation
FROM users
WHERE acceptance_rate >= 70 AND total_answers >= 5
```

### 4. v_tag_statistics - 标签统计视图
```sql
-- 标签使用频率和趋势分析
SELECT 
    tag_id, tag_name, usage_count, 
    recent_usage, trend_direction
FROM tags WITH usage statistics
```

### 5. v_activity_statistics - 活跃度统计视图
```sql
-- 用户活跃度分析
SELECT 
    user_id, daily_activities, weekly_activities,
    activity_type_distribution, last_7_days_trend
FROM activity_logs
```
