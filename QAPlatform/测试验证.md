### 2. API功能测试

#### 用户注册
```bash
curl -X POST http://localhost:8080/api/users/register \
  -H "Content-Type: application/json" \
  -d '{"username":"demouser","password":"password123","email":"demo@example.com"}'
```

期望返回：
```json
{
  "success": true,
  "message": "注册成功",
  "user": {
    "id": 1,
    "username": "demouser",
    "email": "demo@example.com",
    "role": "USER",
    "reputation": 0
  }
}
```

#### 用户登录
```bash
curl -X POST http://localhost:8080/api/users/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demouser","password":"password123"}'
```

期望返回：
```json
{
  "success": true,
  "message": "登录成功",
  "token": "fake-jwt-token-1",
  "user": { ... }
}
```

#### 创建问题
```bash
curl -X POST http://localhost:8080/api/questions \
  -H "Content-Type: application/json" \
  -d '{"title":"如何学习Java？","content":"我是Java初学者，请问有什么好的学习路径？","authorId":1,"tagNames":["Java","学习"]}'
```

#### 获取问题列表
```bash
curl http://localhost:8080/api/questions
```

期望返回分页的问题列表。

### 4. 设计模式验证

系统中实现的8种设计模式：

1. **观察者模式**: 通知系统和事件监听
2. **策略模式**: 搜索策略(`SearchContext`)
3. **工厂模式**: 用户创建工厂(`UserFactory`)
4. **装饰器模式**: 问题装饰器(`QuestionDecorator`)
5. **单例模式**: Spring Bean管理
6. **代理模式**: Spring AOP和JPA代理
7. **外观模式**: Spring Boot启动类
8. **MVC模式**: Spring MVC架构

### 5. 数据库验证

#### H2数据库控制台
1. 访问 http://localhost:8080/api/h2-console
2. 使用以下连接信息：
   - JDBC URL: jdbc:h2:mem:testdb
   - User Name: sa
   - Password: password
3. 查看表结构和数据

#### MySQL数据库切换（可选）
如需要持久化数据，可以：
1. 确保MySQL服务运行
2. 执行 `mysql_setup.sql` 创建数据库
3. 修改 `application.properties` 切换到MySQL配置
4. 重启应用
