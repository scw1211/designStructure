# 🗄️ 数据库草稿功能实现报告

## 🎯 问题解决

### 用户反馈
> "啊，为什么我没在数据库里看到"

**根本原因：** 之前的草稿功能只是"假保存"，数据并未真正存储到数据库中。

## ✅ 解决方案

### 1. 📊 数据库实体设计

创建了完整的 `QuestionDraft` 实体类：

```java
@Entity
@Table(name = "question_drafts")
public class QuestionDraft {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;                    // 草稿唯一标识
    
    private String title;               // 草稿标题
    private String content;             // 草稿内容  
    private String tags;                // 标签（JSON格式）
    private Boolean autoSaved;          // 是否自动保存
    private String draftName;           // 草稿名称
    
    @ManyToOne(fetch = FetchType.LAZY)
    private User author;                // 草稿作者
    
    @CreationTimestamp
    private LocalDateTime createdAt;    // 创建时间
    
    @UpdateTimestamp  
    private LocalDateTime updatedAt;    // 更新时间
}
```

### 2. 🔧 Repository接口

实现了完整的数据库操作接口：

```java
@Repository
public interface QuestionDraftRepository extends JpaRepository<QuestionDraft, Long> {
    // 按用户查询草稿
    List<QuestionDraft> findByAuthorIdOrderByUpdatedAtDesc(Long authorId);
    
    // 查找最新自动保存草稿
    Optional<QuestionDraft> findLatestAutoSavedDraft(Long authorId);
    
    // 清理空草稿
    void deleteEmptyDrafts(Long authorId);
    
    // 其他查询方法...
}
```

## 📈 数据库结构

### question_drafts 表结构

| 字段名 | 类型 | 约束 | 描述 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 草稿ID |
| title | VARCHAR(200) | - | 草稿标题 |
| content | TEXT | - | 草稿内容 |
| tags | JSON | - | 标签列表 |
| author_id | BIGINT | NOT NULL, FOREIGN KEY | 作者ID |
| auto_saved | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否自动保存 |
| draft_name | VARCHAR(100) | - | 草稿名称 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

### 索引设计

- **主索引：** `PRIMARY KEY (id)`
- **作者索引：** `INDEX idx_author_id (author_id)`
- **时间索引：** `INDEX idx_updated_at (updated_at)`
- **自动保存索引：** `INDEX idx_auto_saved (auto_saved)`
