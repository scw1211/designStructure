# QA平台启动指南

## 后端启动步骤

### 1. 进入后端目录
```bash
cd /Users/scw/Downloads/课设/QAPlatform/backend
```

### 2. 清理旧进程（如果需要）
```bash
# 清理8080端口
lsof -ti :8080 | xargs kill -9 2>/dev/null || echo "端口清理完成"

# 清理Spring Boot进程
pkill -f "spring-boot" && sleep 2
```

### 3. 编译项目
```bash
mvn clean compile
```

### 4. 启动后端服务
```bash
# 方式1：前台启动（推荐，可以看到日志）
mvn spring-boot:run

# 方式2：后台启动
mvn spring-boot:run > backend.log 2>&1 &
```

### 5. 验证启动
```bash
# 检查进程
ps aux | grep java | grep qa-platform

# 检查端口
lsof -i :8080

# 测试API
curl http://localhost:8080/api/test/status
```

## 常见问题解决

### 问题1：端口被占用
```bash
# 查看占用8080端口的进程
lsof -i :8080

# 强制杀死进程
kill -9 <PID>
```

### 问题2：Maven找不到spring-boot插件
- 确保在backend目录下执行maven命令
- 检查pom.xml文件是否存在

### 问题3：数据库连接失败
- 确保MySQL服务正在运行
- 检查application.properties中的数据库配置
- 确保数据库密码正确（当前配置：newpassword）

## 启动顺序建议

1. 先启动MySQL数据库
2. 启动后端服务（mvn spring-boot:run）
3. 启动前端服务（npm run dev）
4. 访问前端界面进行测试
