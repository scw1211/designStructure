# 主页问题界面修复报告

## 修复时间

## 问题描述
用户反映主页的问题界面什么都没有显示，问题列表为空。

## 问题分析

### 根本原因
前端API配置问题导致CORS错误，具体表现为：

1. **API配置错误**: 前端`src/api/index.ts`中的`baseURL`设置为绝对路径`http://localhost:8080/api`
2. **绕过代理**: 这样配置会绕过Vite开发服务器的代理配置
3. **CORS问题**: 直接跨域请求可能被浏览器阻止
4. **数据加载失败**: 导致主页问题列表显示为空

### 技术细节
- 前端运行在 `localhost:5173`
- 后端运行在 `localhost:8080` 
- Vite配置了代理: `/api` -> `http://localhost:8080`
- 但前端代码没有使用代理，而是直接访问后端

## 修复方案

### 1. 修改API配置
**文件**: `QAPlatform/frontend/src/api/index.ts`

**修改前**:
```javascript
const api = axios.create({
  baseURL: 'http://localhost:8080/api', // 直接访问后端
  // ...
})
```

**修改后**:
```javascript
const api = axios.create({
  baseURL: '/api', // 使用相对路径，让Vite代理处理
  // ...
})
```

### 2. 验证代理配置
**文件**: `QAPlatform/frontend/vite.config.ts`

确认代理配置正确:
```javascript
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

## 技术要点

### CORS和代理的重要性
1. **开发环境**: 前端(5173) + 后端(8080) = 跨域
2. **Vite代理**: 解决开发环境跨域问题
3. **配置一致**: 前端API配置必须使用代理路径

### 最佳实践
1. 开发环境使用相对路径 (`/api`)
2. 生产环境可以使用绝对路径或环境变量
3. 确保代理配置和API配置匹配
